# 🎬 Video Maker Pro

Десктопное приложение для работы с изображениями, видео, аудио и PDF: конвертация форматов,
создание видео из фото, склейка роликов, сжатие, водяные знаки и удаление метаданных.
Тёмный интерфейс, всё в одном окне. **Python пользователю устанавливать не нужно.**

[![version](https://img.shields.io/github/v/release/BomBilka1/png-to-mp4)](../../releases/latest)
![platform](https://img.shields.io/badge/platform-Windows%2010%2F11-lightgrey)

## ✨ Возможности

- 🖼 **Конвертер фото** — png, jpg, webp, bmp, tiff, ico
- 🎬 **Конвертер видео** — mp4, avi, mov, mkv, webm, gif
- ✨ **Создание видео из фото** (H.264, настраиваемая длительность)
- 🔗 **Склейка** нескольких видео в одно
- 📦 **Сжатие** фото и видео с выбором качества
- 🎵 **Аудио** — конвертация, обрезка, склейка, громкость
- 📄 **PDF** — объединение, разделение, сжатие, удаление, извлечение и поворот
  страниц с предпросмотром: миниатюры всех страниц, выбор кликом
- 🔧 **Инструменты**: водяные знаки, удаление EXIF/GPS-метаданных
- 🔄 **Автообновление** через GitHub Releases

## 📥 Установка

Скачайте `VideoMakerPro_Setup.exe` со страницы [**Releases**](../../releases/latest)
и запустите. Установщик создаст ярлык на рабочем столе и в меню Пуск.

**Требования:** Windows 10/11 64-bit, ~200 МБ на диске. ffmpeg встроен.

## 🔄 Автообновление

Программа при запуске проверяет [Releases](../../releases) этого репозитория.
Если доступна более новая версия — предложит скачать и установить её автоматически.

## 🚀 Выпуск новой версии

Сборку делает GitHub Actions на Windows-раннере — локально ничего собирать не нужно.

1. Поднять версию **в двух местах**: `VERSION` в `convert_v8.py` и `MyAppVersion`
   в `installer.iss` (значения должны совпадать, иначе сборка упадёт на проверке)
2. Описать изменения в `RELEASE_NOTES.md` — этот текст станет описанием релиза
3. Поставить тег и запушить:

```bash
git tag v8.3.2 && git push origin v8.3.2
```

Через ~10 минут релиз с приложенным `VideoMakerPro_Setup.exe` появится на странице
Releases, и установленные копии программы увидят обновление.

Чтобы просто проверить сборку без публикации — вкладка **Actions** → *Build and
release* → **Run workflow**. Установщик окажется в артефактах запуска.
