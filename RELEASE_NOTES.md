Установка и обновление больше не требуют прав администратора.

- Программа ставится в профиль пользователя (%LocalAppData%\Programs\Video Maker Pro)
  вместо Program Files, окно UAC при установке и обновлении не появляется
- Установка выполняется для текущего пользователя Windows

ВНИМАНИЕ при переходе с версии 8.3.2 и старее: сначала удалите старую
версию через «Параметры → Приложения», иначе на компьютере останутся две копии.
